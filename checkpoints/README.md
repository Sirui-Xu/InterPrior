# Pretrained Policy

Download [interprior_smpl.pth](https://github.com/Sirui-Xu/InterPrior/releases/latest/download/interprior_smpl.pth), or use the [complete inference bundle](https://github.com/Sirui-Xu/InterPrior/releases/latest/download/interprior-inference.zip). This is the released InterPrior policy for the SMPL humanoid, including the model parameters and observation normalization statistics used by `InterPriorPolicy`.

Keep the model in this directory or select another location with `--checkpoint`.
